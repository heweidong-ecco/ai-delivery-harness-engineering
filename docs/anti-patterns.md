# 反模式

## 编码反模式

| 反模式             | 问题         | 正解                |
| ------------------ | ------------ | ------------------- |
| 裸 except          | 吞异常       | 捕获具体异常        |
| 金额用 float       | 精度丢失     | 用 int 分或 Decimal |
| 外部调用无 timeout | 线程堆积     | 必须设 timeout      |
| api 直接访问 DB    | 事务边界混乱 | 走 service          |
| domain 依赖 ORM    | 领域不纯     | 依赖倒置            |
| 硬编码配置         | 环境不可移植 | 走配置中心          |
| print 调试         | 无法采集     | 用 logging          |
| 超长函数           | 难维护       | 拆分                |
| 深嵌套             | 难读         | 提前返回            |
| 重复代码           | 维护成本     | 提取                |
| 魔法数字           | 难理解       | 常量化              |
| 可变默认参数       | 共享状态     | 用 None             |
| 循环 import        | 启动失败     | 重构                |
| 同步阻塞 IO        | 性能差       | 异步或线程池        |
| N+1 查询           | 性能差       | 批量查询            |
| 无索引查询         | 性能差       | 加索引              |
| 大事务             | 锁竞争       | 拆小事务            |
| 无幂等             | 重复执行     | 幂等键              |
| 时区混用           | 时间错乱     | 统一 UTC            |
| 无缓存             | 性能差       | 按需缓存            |
| 无降级             | 级联失败     | 降级策略            |
| 无重试             | 偶发失败     | 有限重试            |
| 无熔断             | 雪崩         | 熔断                |
| 无限流             | 被打垮       | 限流                |
| 无监控             | 盲区         | 埋点                |
| 无日志             | 难排查       | 结构化日志          |
| 无 trace           | 难追踪       | trace_id            |
| 无测试             | 回归风险     | 必须测试            |
| 无文档             | 难维护       | 更新文档            |

## 流程反模式

| 反模式            | 问题     | 正解         |
| ----------------- | -------- | ------------ |
| 跳过评审          | 质量失控 | 必须评审     |
| 跳过测试          | 回归风险 | 必须测试     |
| 跳过 CI           | 带病合并 | 必须 CI      |
| 跳过人工确认      | 决策失误 | 五个确认点   |
| 一次性大改        | 难回滚   | 小步快跑     |
| 无回退方案        | 故障扩大 | 必须回退     |
| 无来源规则        | 假规则   | 必须有来源   |
| 无测试规则        | 死规则   | 必须有测试   |
| 无 Owner 规则     | 无人负责 | 必须有 Owner |
| Agent 直接改 main | 失控     | 必须走 PR    |
