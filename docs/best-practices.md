# 最佳实践

## 规则

- 每条规则必须有来源。
- 每条规则必须可程序化验证。
- 每条 P0 规则必须有测试。
- 每条规则必须有 Owner。
- 每条规则有变更历史。

## 技能

- 每个技能必须有触发条件。
- 每个技能必须有质量门禁。
- 每个技能必须有失败回退。
- 每个技能必须有加载时机。

## 知识库

- 按需查询，不全量加载。
- 每条知识必须有来源。
- 缺失写“待补充”。
- 不主动编造。

## Agent

- 执行与评判分离。
- 不允许跳过人工审核。
- 不允许直接改 main。
- 每个 Agent 独立分支、独立 PR。

## 流程

- 十阶段不可跳过。
- 五个确认点必须人工。
- 评审循环有上限。
- 超限升级人工。
- 流程一致性优先于效率。

## 质量

- 门禁可程序化。
- 测试数 > 0。
- 覆盖率 >= 80%。
- CI 必须通过。
- 无密钥、无真实数据。

## 沉淀

- 每次问题 Patch 回 Harness。
- 每条 Patch 有来源。
- 每条 Patch 有测试。
- 每条 Patch 有审核。
