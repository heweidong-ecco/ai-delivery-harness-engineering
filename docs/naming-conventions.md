# 命名约定

## 文件

- 规则：`<domain>-<type>.md`，如 `python-coding-standard.md`
- 技能：`SKILL.md` 或 `<name>-sop.md`
- 需求目录：`REQ-XXXX`
- 热修目录：`HOTFIX-XXXX`
- 发布目录：`RELEASE-XXXX`
- 事故：`INC-YYYY-MMDD`
- Agent：`<name>-agent.md`

## 分支

- `feature/<name>`
- `fix/<name>`
- `docs/<name>`
- `agent/<name>`
- `hotfix/<name>`
- `rule/<id>`

## 提交

`<type>: <subject>`

## 规则 ID

`<DOMAIN>-<NNN>`，如 `PAY-001`、`SEC-001`

## 测试

`test_<module>_<behavior>.py`
