# Harness 度量指标

## 一、核心指标

| 指标               | 目标   | 当前   | 趋势   | 采集方式        | 频率 | 告警阈值 |
| ------------------ | ------ | ------ | ------ | --------------- | ---- | -------- |
| 项目维度 AI 代码率 | 90%    | <待填> | <待填> | Git 提交统计    | 每日 | < 70%    |
| 个人维度 AI 代码率 | 85%    | <待填> | <待填> | Git 提交统计    | 每日 | < 60%    |
| 返工轮次           | 1      | <待填> | <待填> | PR Review 记录  | 每周 | > 2      |
| 人工确认轮次       | 1      | <待填> | <待填> | checkpoint 记录 | 每周 | > 2      |
| 质量门禁通过率     | 100%   | <待填> | <待填> | CI 结果         | 实时 | < 90%    |
| 测试覆盖率         | >=80%  | <待填> | <待填> | pytest-cov      | 每次 | < 80%    |
| 需求交付周期       | <待填> | <待填> | <待填> | 需求目录时间戳  | 每月 | <待填>   |

### 采集方式

- **AI 代码率**：`git log --grep="agent:" | wc -l` / `git log --oneline | wc -l`
- **返工轮次**：`review-record-v*.md` 文件数
- **人工确认轮次**：`harness/checkpoints/` 下文件数
- **门禁通过率**：CI 成功次数 / 总次数
- **覆盖率**：`pytest --cov` 输出

### 计算脚本

```bash
# 规则条数
grep -c "规则 ID" harness/rules/*.md

# 来源覆盖率
grep -c "source:" harness/rules/*.md

# 可程序化率
grep -c "check:" harness/rules/*.md

# 测试覆盖率
grep -c "test:" harness/rules/*.md
```

  - 告警阈值是否明确
  - 看板是否可用
