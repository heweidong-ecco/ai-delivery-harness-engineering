# 回滚手册

## 回滚类型

| 类型     | 适用     | 命令   |
| -------- | -------- | ------ |
| 代码回滚 | 代码问题 | <命令> |
| 配置回滚 | 配置问题 | <命令> |
| 数据回滚 | 数据问题 | <命令> |
| 依赖回滚 | 依赖问题 | <命令> |

## 回滚决策

| 条件         | 决策人 | 时限    |
| ------------ | ------ | ------- |
| 关键路径不通 | <角色> | 5 分钟  |
| 监控异常     | <角色> | 10 分钟 |
| 数据异常     | <角色> | 立即    |

## 回滚后

1. 验证主链路。
2. 验证国际化链路。
3. 验证数据一致性。
4. 监控观察 30 分钟。
5. 记录到 patch-log.md。
