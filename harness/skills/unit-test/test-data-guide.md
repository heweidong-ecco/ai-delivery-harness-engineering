# 测试数据指南

## 原则

- 优先使用线上真实请求的脱敏出入参。
- 禁止使用真实用户数据。
- 禁止使用生产密钥。

## 数据来源

| 来源         | 用途     | 脱敏要求 |
| ------------ | -------- | -------- |
| 线上请求日志 | 真实场景 | 必须脱敏 |
| 人工构造     | 边界     | 无       |
| Fixture      | 重复场景 | 无       |

## 脱敏规则

- 手机号：保留前 3 后 4
- 身份证：保留前 6 后 4
- 银行卡：保留后 4
- 邮箱：保留首字母 + 域名
- 姓名：保留姓

## 存放

- 小数据：tests/fixtures/
- 大数据：tests/data/（gitignore）

## 禁止

- 禁止提交真实数据。
- 禁止提交生产密钥。
- 禁止提交未脱敏日志。
