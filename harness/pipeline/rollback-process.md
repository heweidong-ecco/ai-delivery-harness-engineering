# 回滚流程

## 触发

- 关键路径不通
- 监控异常
- 数据异常

## 流程

1. 决策人确认回滚。
2. 执行回滚命令。
3. 验证回滚结果。
4. 监控观察。
5. 记录到 patch-log.md。
6. 复盘。
