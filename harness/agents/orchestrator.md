# Orchestrator Agent

## 目标

编排 6 个填充 Agent 按顺序执行。

## 输入

harness/sources/ 下所有来源。

## 步骤

1. 检查来源完整性。
2. 按顺序触发 Agent。
3. 收集输出。
4. 生成审核清单。
5. 提交 PR。

## 输出

- 每个 Agent 的输出文件
- 审核清单
- PR 描述

## 硬性约束

- 不允许跳过任何 Agent。
- 不允许跳过人工审核。
- 每个 Agent 独立分支。
- 每个 Agent 独立 PR。
- 来源为空则拒绝。
