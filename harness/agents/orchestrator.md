# Orchestrator Agent

## 目标
编排全部填充 Agent 按顺序执行。

## 输入
harness/sources/ 下所有来源。

## 执行阶段

### 阶段 1：核心（必须）

| Agent       | 状态   | 分支 | PR  |
| ----------- | ------ | ---- | --- |
| 架构解析    | 待开始 |      |     |
| 事故反推    | 待开始 |      |     |
| Review 提炼 | 待开始 |      |     |
| 代码考古    | 待开始 |      |     |
| 数据建模    | 待开始 |      |     |
| 门禁解析    | 待开始 |      |     |

### 阶段 2：扩展（可选）

| Agent | 状态   | 分支 | PR  |
| ----- | ------ | ---- | --- |
| 安全  | 待开始 |      |     |
| 性能  | 待开始 |      |     |
| 重构  | 待开始 |      |     |
| 依赖  | 待开始 |      |     |
| 文档  | 待开始 |      |     |

## 步骤

1. 检查来源完整性。
2. 按顺序触发 Agent。
3. 收集输出。
4. 生成审核清单。
5. 提交 PR。

## 硬性约束

- 不允许跳过任何 Agent。
- 不允许跳过人工审核。
- 每个 Agent 独立分支、独立 PR。
- 来源为空则拒绝。
- 阶段 2 可跳过，但阶段 1 必须完成。
