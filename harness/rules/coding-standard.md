# 项目编码规范

## 强制规则

- 价格字段必须用 Long，单位分，禁止 Double 和 Float。
- 外部服务调用必须设置超时和降级。
- 流程编排组件内不写大段业务逻辑，必须委托 Service。
- 主链路修改必须同步检查国际化链路。
- 新增接口必须同步新增单测。
- 禁止提交密钥、真实用户数据、生产配置。

## 可程序化验证

- 静态检查价格字段类型。
- 扫描外部调用是否有超时与降级。
- 检查流程编排组件业务逻辑行数。
